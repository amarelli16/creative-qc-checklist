# 🎬 Creative QC Checklist & Rules (Meta Ads)

Динамический регламент и чек-лист контроля качества креативов для Meta Ads (MindBodyFace).

## 🔗 Прямая ссылка для веб-сервиса
Веб-сервис Creative QC автоматически забирает актуальную версию по ссылке:
```
https://raw.githubusercontent.com/amarelli16/creative-qc-checklist/main/checklist.json
```

## 📝 Как обновлять чек-лист
1. Откройте файл [checklist.json](checklist.json) прямо на GitHub.
2. Нажмите иконку ✏️ (**Edit this file**).
3. Добавьте или отредактируйте правила, примеры, формулировки или AI-промпты.
4. Нажмите **Commit changes**.
5. Изменения сразу станут доступны в сервисе Creative QC!

## 📂 Структура категорий чек-листа
- 🛑 **Meta Ad Policies & Violations** (критические запреты: до/после, зум проблемных зон, сенситивные темы, ложные медицинские обещания)
- 📐 **Safe Zones & Formats** (безопасные зоны 9:16 Reels/Stories, 4:5, 1:1, UI оверлеи)
- ⚡ **Hook (0–3 секунды)** (первый кадр, субтитр, зацепка внимания)
- 👁️ **Visual Style & Readability** (шрифты, контраст, плашки, скорость смены кадров)
- 🔊 **Audio & Voiceover** (испанский дубляж/озвучка, эмоции, темп, субтитры)
- 🎬 **Video Production Quality** (живые кадры vs AI/сток, отсутствие полос)
- ✍️ **Meta Ad Copy Rules** (sensational claims, отсутствие кликбейта, капса)
